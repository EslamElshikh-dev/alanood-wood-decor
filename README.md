# مؤسسة العنود للديكور الخشبي

موقع ثابت جاهز للنشر على GitHub Pages والدومين المخصص: `https://alanoudfaraj.com`.

## الرفع
1. ارفع محتويات مجلد `alanood-wood-decor` إلى المستودع.
2. فعل GitHub Pages من Settings > Pages.
3. اربط الدومين `alanoudfaraj.com` من إعدادات Pages.
4. في GoDaddy أضف سجلات GitHub Pages حسب تعليمات GitHub.
5. بعد النشر أرسل `sitemap.xml` في Google Search Console.
