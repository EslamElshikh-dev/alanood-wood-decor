# موقع مؤسسة العنود للديكور الخشبي

موقع Static جاهز للنشر على GitHub Pages لمؤسسة نجارة وديكور خشبي في الرياض.

## الملفات المهمة

- `index.html` الصفحة الرئيسية.
- `services/` صفحات الخدمات المستقلة للسيو.
- `assets/css/style.css` ملف التصميم، ويحتوي على توقيع المطور في الفوتر.
- `assets/js/main.js` وظائف القائمة، الوضع الليلي، حالة العمل، نموذج الواتساب.
- `assets/images/logo/logo-main.png` الشعار الرئيسي.
- `assets/images/logo/logo-icon.png` أيقونة الشعار.
- `assets/images/services/` صور الخدمات بصيغة WebP.
